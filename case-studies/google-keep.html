Google Keep Clone

Rebuilding an everyday tool to learn how small interactions create trust.

ReactLocal StorageNotes UXRepository available

The Brief

Understand the ordinary.

The project recreates the core experience of a notes tool: capture an idea quickly, organise it lightly and return to it later without friction. Everyday products are demanding because their value depends on trust, speed and small moments of feedback.

I used the familiar note-board model as a constraint: the interface should be quiet enough to disappear, but expressive enough to help a person remember what matters.

My Approach

Make state legible.

I worked through note creation, editing, pinning, archiving, colour coding and grid/list views with React components and local storage persistence.

The key implementation question was not only how to create a note, but how each action should remain reversible, visible and predictable after a refresh.

What I Learned

Feedback needs rhythm.

Tiny cues — saved state, clear empty states and predictable controls — have an outsized effect on whether an interface feels dependable.

This project made the invisible work visible: data shape, component boundaries and the order in which state updates reach the screen all affect the feeling of quality.

Outcome

A focused React study.

The clone is a real repository and a foundation for further refinement. A verified live deployment has not been configured yet, so the portfolio labels that status honestly. The case study keeps the emphasis on what was learned and what can be improved next.
