PawFinder

Designing a calmer path from dog discovery to meaningful next steps.

ReactContext APIResponsive UILive build

The Brief

Make discovery feel clear.

PawFinder is a responsive dog discovery platform built around approachable browsing, useful filtering and a clear route into breed detail. The challenge was to keep the experience warm while giving a visitor enough structure to move from a broad search to a confident next step.

I treated the interface as a small product system rather than a collection of cards: content hierarchy, filter behaviour, empty states and detail transitions all needed to agree.

My Approach

Structure before decoration.

I focused on reusable React components, shared state and progressive disclosure. Search and filtering stay close to the user’s intent, while responsive cards preserve the same hierarchy across screen sizes.

The work also meant designing the connective tissue: predictable loading, readable states and actions that remain discoverable when the layout collapses on smaller screens.

What I Learned

State is part of the interface.

The most important decisions were not visual tricks. They were the rules that kept filters, favourites and details in sync. Good frontend work makes those rules feel invisible.

This build sharpened my understanding of how a small context layer can reduce prop friction while still keeping the user’s mental model simple.

Outcome

A useful, deployable build.

The result is a live React application with a focused discovery flow, responsive behaviour and a codebase that can grow into a deeper adoption experience. The screenshots show the visual surface; the repository shows the component and state decisions underneath it.
